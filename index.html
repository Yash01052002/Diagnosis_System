01 · PRODUCT

One place for the entire crash investigation.

BlackBox connects raw crash evidence, firmware symbols, engineering knowledge and local AI into one repeatable workflow.

01

Crash ingestion

Capture fault metadata, registers, stack words, firmware identity and device information.

02

Deep symbolication

Resolve PC and LR addresses to functions, source files and line numbers with ELF debug symbols.

03

Grounded diagnosis

Retrieve relevant STM32 and FreeRTOS references before generating the root cause and fix.

04

Private local AI

Run Llama 3.1 through Ollama so crash data can remain on your machine.

05

Build registry

Index ELF/MAP artifacts by firmware and build version for reliable crash matching.

06

Actionable dashboard

Review crashes, devices, symbols, diagnosis history and recommended fixes.

05 · QUICK START

Run BlackBox locally.

Docker Desktop and Ollama are the only major prerequisites.

1

Install prerequisites

docker --version
ollama --version
2

Pull the model

ollama pull llama3.1
3

Clone BlackBox

git clone https://github.com/Yash01052002/Diagnosis_System.git
cd Diagnosis_System
4

Configure Ollama

LLM_PROVIDER=ollama
OLLAMA_BASE_URL=http://host.docker.internal:11434
OLLAMA_CHAT_MODEL=llama3.1
5

Start services

docker compose up -d --build
6

Open BlackBox

Dashboard: http://localhost:3000
API Docs:  http://localhost:8000/docs
